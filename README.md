# Яндекс.Афиша: продуктовая аналитика, трек Б

Индивидуальный проект по дисциплине «Продуктовая аналитика», осень 2026. Исторические учебные данные июнь 2017 — май 2018. Анализ не описывает актуальную деятельность Яндекс.Афиши.

## Задача

Определить пользовательскую ценность и экономику привлечения через пирамиду метрик: North Star (уникальные платные покупатели), C30 (конверсия), M1 retention (возврат в следующий календарный месяц) и guardrail CAC / revenue LTV90. Построить когортный retention и сравнить 90-дневную наблюдаемую выручку на пользователя с расходами на привлечение. Покупатели, источники, когорты и расходы согласованы по периодам.

## Запуск в Google Colab

2. **Файл → Загрузить блокнот** и выберите `PA_S1_Afisha_Track_B.ipynb` из скачанного проекта. Либо на вкладке **GitHub** вставьте ссылку на ноутбук из репозитория.
3. **Среда выполнения → Выполнить все**.

## Откуда данные

- Визиты: https://code.s3.yandex.net/datasets/visits_log.csv
- Заказы: https://code.s3.yandex.net/datasets/orders_log.csv
- Рекламные расходы: https://code.s3.yandex.net/datasets/costs.csv
- Контрольная информация: `data/manifest.json` (URL, SHA-256, размер и примечание о лицензии).

CSV загружаются **автоматически** по HTTPS в `data/raw/` с проверкой SHA-256. Источники являются публичными учебными файлами. Kaggle-зеркало сообщает лицензию Apache 2.0, однако лицензия первичного издателя на повторное распространение не подтверждена, поэтому сырые CSV **не размещаются в этом репозитории**. Если первичные URL исчезнут или изменятся, потребуется согласовать новый проверяемый источник. Учебный анализ имеет ограничения: нет себестоимости, подтверждённой маржи, регистраций, order_id, отметок тестовых пользователей и подтверждённого согласия субъектов.

## Что получилось и как интерпретировать

Ноутбук строит качество данных, DAU/WAU/MAU, C30, календарную когортную матрицу M0/M1/M2…, удержание R7–13, LTV90/CAC по зрелым когортам, разбивку по каналам и чувствительность к крупным заказам. Итоговые численные результаты появятся при выполнении всех ячеек; их нельзя считать текущими показателями продукта. Наблюдаемый revenue LTV90 — **не прибыль и не полный lifetime LTV**, поскольку маржа неизвестна.
